# Система маршрутизации заявок сервиса заказа такси

**Вариант 26:** `ИБ | ИЗ2 | ПЗ1 | Д1ОЗ3 | Д1ОО4 | Д2П2 | Д2Б3 | ОР1 | ОД2`

Имитационная модель СМО: зоны города генерируют заявки на поездку, заявки ждут в ограниченном буфере диспетчерской, водители их обслуживают.

## Расшифровка варианта

| Код | Значение |
|---|---|
| ИБ | бесконечный источник (зоны города) |
| ИЗ2 | равномерный закон интервалов между заявками |
| ПЗ1 | экспоненциальное время обслуживания (поездка) |
| Д1ОЗ3 | постановка в буфер на первое свободное место, без сдвига |
| Д1ОО4 | при переполнении выбивается заявка, позже всех вставшая в буфер |
| Д2П2 | выбор водителя по кольцу |
| Д2Б3 | выбор заявки из буфера по кольцу |
| ОР1 | автоматический режим: сводная таблица результатов |
| ОД2 | пошаговый режим: формализованная схема и состояние модели |
